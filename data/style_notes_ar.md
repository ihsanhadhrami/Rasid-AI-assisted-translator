# Rāṣid — Style Notes

These are house rules for drafting Arabic briefs. Use them together with `Glossary.md`, which covers terms, and `brief_template.md`, which covers layout.
Each rule is marked **[Decided]** (confirmed by the reviewer) or **[Default]** (in use until the reviewer confirms or changes it).

---

## 1. Register and tone
- **[Decided]** Write formal Modern Standard Arabic in the style of WAM (the UAE news agency): plain, neutral, wire-service register.
- **[Decided]** Do not add information that is not in the source. Do not soften or strengthen the source's claims.
- **[Default]** Avoid evaluative adjectives (خطير، تاريخي، غير مسبوق). Use one only when the source uses it, and attribute it to the source.
- **[Default]** Mark opinion and analysis pieces as such in the summary, for example: (مقال رأي) or (تحليل نشره موقع …).

## 2. Attribution
- **[Decided]** Every claim must be attributed. Never present a claim as fact.
- **[Decided]** An unnamed "reportedly" stays unnamed. Do not invent a source.
- **[Decided]** When the outlet adds its own analysis on top of a reported fact, attribute that analysis to the outlet separately, for example ويرى الموقع أن…
- Map Malay hedging words to Arabic as follows, without dropping or adding any hedge:

| Malay | Arabic | Notes |
|---|---|---|
| dilaporkan | أفادت تقارير / بحسب التقارير | Use a different form on the second occurrence, e.g. وأشارت التقارير |
| menurut / memetik | وفقاً لـ / نقلاً عن | نقلاً عن is for direct quotes and statements |
| dikatakan | ذُكر أن | |
| dipercayai | يُعتقد أن | |
| dijangka | من المتوقع أن | |
| berkemungkinan | من المحتمل أن | |
| didakwa | ادُّعي أن / بحسب ادعاءات | Always flag this one. It is an allegation, and the wording affects legal tone |

## 3. Word choice: intensity calibration
- **[Decided]** When two Arabic words are both correct, pick the one that matches the source's intensity, not the more dramatic one.
  - Example: *kebuntuan* → **مأزق**, not انسداد. See the glossary.
- **[Default]** Any near-synonym choice that changes intensity goes in FLAGS.

## 4. Names and titles
- **[Default]** Gulf royals get the WAM honorific (صاحب السمو الملكي / صاحب السمو), but only titles the source mentions. Do not add offices such as رئيس مجلس الوزراء unless the source states them.
- **[Default]** Malaysian honorifics (Tan Sri, Datuk Seri, Dato') go in full in the fact table and are left out of the running Arabic text. *Needs confirmation.*
- **[Decided]** Every military rank is flagged unless the glossary already covers it. Malaysian and UAE rank systems do not map one-to-one.
- **[Default]** Use the established Arabic spelling for well-known names (أنور إبراهيم، نتنياهو). Transliterate other names and list them in the fact table.

## 5. Sensitive terminology
- **[Default]** Houthis → **الحوثيون** (neutral). WAM house style often uses ميليشيا الحوثي, but use that only if the reviewer decides on it. *Needs confirmation.*
- **[Default]** Use the source's own wording for armed groups, conflicts and disputed territories. Flag each one for review.

## 6. Dates, numbers and places
- **[Decided]** Write month names in the أكتوبر style, never تشرين.
- **[Default]** Date format: 14 أكتوبر 2026, as in the template.
- **[Default]** Use Western digits (0–9).
- **[Default]** Currency: RM → رينغيت ماليزي, e.g. 500 مليون رينغيت ماليزي. Do not convert amounts unless the source does.
- **[Default]** Add a dateline only when the source gives one. If it doesn't, flag "no dateline/date in source" and ask.

## 7. Scope and relevance
- **[Default]** If an article does not involve Malaysia or the UAE directly (for example, a Malaysian outlet covering the Gulf), say so in FLAGS and keep the significance section brief. Do not invent a link to the UAE or Malaysia.
